What safety stock is

An upward adjustment to the target Days-on-Hand (DOH), resolved per (item, location, supplier) at calculation time. Not a stored buffer quantity. Higher target DOH ⇒ bigger replenishment order.

Gotchas worth remembering

  • FLS is separate from deploy. New optional fields deploy but aren't queryable until npm run update:fls -- <org> runs. Required on every fresh-org deploy of this feature.
  • Permanent overrides must carry no End Date — a validation rule enforces this (QA fix in PR #442); otherwise the batch would silently expire a “Permanent” row.
  • Known gap: Override_Reason__c is not mandatory at the data layer despite the AC — deferred (would break 8 unrelated test classes). Needs its own ticket.
  • Impact preview aggregate is per-SKU in v1; supplier-tier wire-in to the pick-face path is still gated on the open Q4 product call.
