Red Bull Allocation · BMS-4935 · explained simply

Stocking Red Bull — without the guesswork

How a weekly spreadsheet became an import screen that does the hard math automatically.

🥤 Imagine a teacher hands out 100 cookies to five classrooms. Instead of counting them out herself every week, she writes each classroom's fair share on a note — but someone still has to read the note and hand-carry the cookies to each room. Now imagine doing that wrong and three classrooms get nothing. The "allocation import" is the system that reads the note and delivers the right amount, automatically.

😖 Why it's a problem

  • Every week, Red Bull emails Gulf a spreadsheet that says how many cases of each product Gulf is allowed to buy. That number is called an allocation.
  • Gulf has 5 warehouses across Florida and Alabama. Someone had to open that spreadsheet and manually type each number into the system — five times, for every product, every week.
  • Manual = mistakes. A typo means one warehouse gets too much, another gets too little, and drivers show up with the wrong stock.
  • There was no check for bad data either — a misspelled product code or a negative number just went in quietly.

🧍 Who it hurts

  • Purchasing analysts — spending hours each week on tedious, error-prone data entry.
  • Warehouse teams — getting the wrong quantities because a number was keyed in wrong.
  • Drivers & customers — running out of Red Bull because a warehouse was under-stocked by mistake.

💡 The solution — an import screen that does the work

Upload the file. The system does the rest. The purchasing analyst uploads Red Bull's spreadsheet, and the import screen:
  • 🔍 Checks every row for problems before saving anything — unknown product codes, bad quantities, duplicates are all caught and shown on screen. Clean rows go in; bad rows are listed with a reason and skipped.
  • 🏭 Splits each product automatically across the 5 warehouses using configured percentages: Milton FL gets 30%, Montgomery AL 25%, Mobile AL 20%, Huntsville AL 15%, McCalla AL 10%. The math is guaranteed to add up — no rounding errors.
  • 📅 A week picker lets the analyst pick which week the file is for, preventing accidental date mistakes.
  • ♻️ Re-importing the same week is safe — it just updates, never duplicates.
Think of it as one upload button that replaces a day of spreadsheet work.
