Red Bull Allocation Import

Epic BMS-4935 · story BMS-4120
Demo ✓ (ohfy-val-4120)
User
Gulf purchasing analysts (and downstream: warehouses, drivers, customers)
Impact
Weekly allocation was hand-keyed and split across 5 warehouses manually → wrong stock-on-hand, bad driver limits, customer complaints.
Solution
Upload Red Bull's weekly file → validate (reject unknown SKUs, bad quantities, duplicates) → auto-split across the 5 warehouses by configured % (30/25/20/15/10). Now with a week picker.
Before
Allocations could be stored, but entry was manual spreadsheet keying.
Built now
Import screen + validation + automatic warehouse split + week picker.
💸

Short Pay Review Queue

Epic BMS-4965 · stories BMS-4059 + 4060
Demo ✓ (ohfy-val-4965)
User
AR / finance team and warehouse managers (FL/AL compliance)
Impact
When a store pays less than owed, it became invisible AR; managers hunted balances by hand; in Alabama it's a legal risk to under-collect.
Solution
One queue of every short pay that auto-escalates by FL/AL threshold, flags repeat offenders, and lets AR resolve with credit or mark collected.
Before
System could detect an underpayment (a formula on the invoice), but nothing more.
Built now
Review queue + escalation + repeat-offender rollup + resolution workflow.
🌙

Shift-End Workflow

Epic BMS-5070 · story BMS-4078
Demo ✓ (ohfy-val-4078)
User
Warehouse supervisors, incoming crews, finance/ops reporting
Impact
Breakage was keyed by shift manually (often skipped) → invisible shrinkage that couldn't be tied to a shift, picker, or task.
Solution
An end-of-shift checklist that aggregates breakage + bin counts into one shrinkage number, with pass-down notes for the next crew, before handoff.
Before
Breakage keyed into an old system by hand, frequently skipped.
Built now
Shift-end checklist + breakage review + pass-down notes (Ph1). Total rollup is a future phase.
📦

Safety Stock / Days-of-Inventory

Epic BMS-5068 · story BMS-4217
Backend / data demo
User
Inventory planners (and procurement, sales)
Impact
Buffer stock was gut-feel and undocumented; planners reacted to stockouts after the fact.
Solution
Make the buffer a setting: raise a SKU/supplier's Days-of-Inventory target and the recommended order quantity rises to match — no code change.
Before
Replenishment ordered to static targets; buffers lived in planners' heads.
Built now
DOH-driven order sizing (backend, flag-gated). No screen — it's the math behind ordering.
🗄️

Pick Location Capacity

Epic BMS-5083 · story BMS-4467 (core BMS-3785 done)
Reports — needs org
User
Slotting / replenishment teams and pickers
Impact
Bins got over- or under-filled because slotting ran on informal warehouse knowledge, not product data.
Solution
Give each bin min/max limits derived from the product's case dimensions, and report on which locations are over/under capacity.
Before
Core engine already DONE (BMS-3785): capacity rules on pick locations from case dims.
Built now
Reporting layer (native reports/dashboards). Renders only in a report-eligible org.

The honest frame
