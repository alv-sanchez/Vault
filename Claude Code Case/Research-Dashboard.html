5 Salesforce-Specific Use Cases
USE CASE 1
QueryService / DmlService Compliance
Catch raw SOQL/DML in non-test classes. CLAUDE.md mandate (BMS-3965) with no CI enforcement today.
Security — bypassed AccessLevelResolver
USE CASE 2
Logger-in-Catch Compliance
Every catch must have Logger.getInstance().error() + flush(). Currently manual-only check.
Observability — silent production failures
USE CASE 3
SYSTEM_MODE Audit
Explicit AccessLevel.SYSTEM_MODE needs inline comment citing rules 1/2/3/4/6. Rule 5 citations invalid.
Security — privilege escalation
USE CASE 4
DTO Pattern (ADR-0007)
Cross-package DTOs must be global with { get; set; } accessors. Violations cause silent all-null at runtime.
Runtime — invisible in unit tests
USE CASE 5
Org-Metadata Prefix Drift
managed/ uses ohfy__ prefix, scratch/ uses none. Stale reference breaks nightly snapshot build.
CI — broken snapshot builds
USE CASE 6
Trigger Side-Effect Detection
TriggerHandler cascade: changes to trigger services can break tests/flows on any sObject that fires.
Regression — cascade bugs
USE CASE 7
LWC Reactive Thrashing
Multiple @track/@api mutations in one method cause excessive re-renders. No linter catches this.
Performance — UI jank
USE CASE 8
ServiceLocator Contract Validation
Class renames break Service_Configuration__mdt wiring at runtime. No compile-time check exists.
Runtime — TypeException in prod
6 Recommendation

Hybrid: CI/CD Auto-Review + Manual Deep Dives (Option D)

Start with B1 (ad-hoc agent, Sonnet 4.6) on every non-draft PR to validate cost and noise (~$80-160/mo). Upgrade to B2 (code-review plugin) if quality gap justifies the 5x cost increase. Engineers keep using /audit-pull-request and /code-review for complex changes. This gives 100% PR coverage, convention enforcement via CLAUDE.md, a full audit trail, and complements (not replaces) human review.
