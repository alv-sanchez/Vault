👤 User

Gulf's AR/finance team, recovering freight costs from suppliers instead of Gulf absorbing them silently.

💥 Business impact

Cross-state freight incurred for supplier benefit had no capture point and no path into recovery — Gulf was absorbing costs that contractually belong to suppliers.

🛠️ Intended solution

Adds a freight source (transfer + PO) into the existing billback pipeline (BMS-4141) — not a new parallel system.

🚀 Next phase

Merge #511 → #514 → #516 in order; PO approval needed on the BMS-5792 mockup before any LWC build.

What it is

Captures freight cost on cross-state transfers and on PO reconciliations where a supplier owes Gulf, routing both into Gulf's existing billback ledger. Reshaped from "build a subsystem" to "add a source" after code audit found the billback rails already shipped (BMS-4141).
