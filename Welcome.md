# Welcome

This vault is a template for the Anvil documentation workflow — drafting tickets, testing notes, and living feature docs in Obsidian before pushing them to Jira and Confluence via MCP.

## Start here

- **[[SETUP]]** — new users: one-time config to wire up the `/engineering-notes` skill
- **[[Anvil/README]]** — structure, naming, and workflow
- **[[Anvil/workflow-diagram]]** — visual flowchart
- **`Anvil/Templates/`** — reusable templates for each doc type
- **Example files** — each folder under `Anvil/` has one example (`BMS-0000-example-feature.*`) showing the pattern end-to-end

Delete the examples once your team is comfortable with the workflow.
