- 'Minimum order enforcement per warehouse' conflicts with the existing per-account mechanism (Account.ECOM_Minimum_Case_Quantity__c + Configuration_Preference.EcomMinimumCaseQuantity CMDT from BMS-4171). No threshold values, no per-warehouse data model, no UX for a blocked checkout are specified.
