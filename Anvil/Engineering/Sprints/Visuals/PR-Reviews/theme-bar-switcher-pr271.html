What This Solves

One-click palette switching from the utility bar

themeBarSwitcher is a lightning__UtilityBar LWC that lets a permitted user switch the active theme palette without navigating to the Theme Settings page. It applies new colors instantly on the client and saves the org-wide pointer in the background via the Metadata API.

  • Optimistic recolor — instant client-side :root CSS variable swap via the embedded themeProvider
  • Background persist — setActivePalette enqueues a Metadata API deploy; the switcher polls until confirmed
  • Failure revert — if the save fails, colors revert to the previous palette + error toast
  • Permission gated — only renders for users with the Theme_Switcher custom permission
Kill-Switch Behavior — Customer Theming ON vs OFF

Theming ON

  • Click a palette → page recolors instantly
  • Active-palette pointer saved org-wide
  • Status: "Coastal is now the active palette."
  • Failure → revert to previous palette colors

Theming OFF

  • Click a palette → NO recolor (page stays unthemed)
  • Active-palette pointer still saved org-wide
  • Status: "...will apply when Customer Theming is on."
  • Palette takes effect the moment theming is toggled on
Bugs Fixed

Stale palette on reload

getThemeConfig was @AuraEnabled(cacheable=true) — the LDS cache was never invalidated when the active palette or master toggle changed, so themeProvider repainted stale colors on page reload.

Fix

Changed to plain @AuraEnabled (non-cacheable). One light query per page load — reads fresh every time.

False "active" messaging when theming OFF

Theme Settings page claimed "is now the active palette" even when Customer Theming was disabled — misleading since nothing was actually applied.

Fix

Both the utility-bar switcher and Theme Settings now check themeActive and adjust messaging: "set as active" (not "now active") when theming is off.

Switching Flow
User

Open Utility Bar

Click "Theme" in the utility bar footer. Panel opens, refreshApex re-pulls the kill-switch state.

↓
User

Pick a Palette

Dropdown shows all palettes with two-tone swatch previews. Active palette has aria-checked + accent edge.

↓
Client

Optimistic Recolor

If theming ON: themeProvider.applyPalette() swaps :root CSS tokens instantly.

Skip Recolor

If theming OFF: no visual change. Pointer staged only.

↓
Server

Enqueue Deploy

setActivePalette writes via Metadata API. Returns job ID (not yet durable).

↓
Poll

Confirm Persistence

Poll getThemeSettings via refreshApex every 5s (up to 6 attempts / ~30s) until server confirms the new pointer.

Failure → Revert

Repaint previous palette (or clearPalette() if none). Error toast.
