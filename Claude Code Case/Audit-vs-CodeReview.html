Raw DML bypassing QueryService — security regression

// Engineer writes inline DML instead of using DmlService Database.insert(newRecords, AccessLevel.SYSTEM_MODE); // No AccessLevelResolver check, no rule citation comment // /audit-pull-request: sees nothing wrong — it doesn't know about QueryService mandate // /code-review: reads CLAUDE.md, flags BMS-3965 violation + missing SYSTEM_MODE citation
Why it matters: Raw DML bypasses AccessLevelResolver, which means CRUD/FLS is not enforced. This is a security hole in a managed package — it passes the security review today but violates our own architecture for a reason.
SECURITY — bypassed access control

Catch block without Logger — silent production failure

} catch (Exception e) { System.debug('Error: ' + e.getMessage()); // No Logger.getInstance().error() + flush() // This error vanishes — never reaches Datadog, never pages anyone } // /audit-pull-request: flags System.debug() but NOT the missing Logger call // /code-review: reads CLAUDE.md, flags BMS-4298 Logger-in-catch violation
Why it matters: Errors that only go to System.debug() are invisible in production. No Datadog alert, no ticket, no awareness. The user sees a vague error or silent failure. Our CLAUDE.md mandates Logger.getInstance().error() + flush() in every catch — but the audit skill doesn't know that rule exists.
OBSERVABILITY — invisible production errors
Missed by /audit

DTO missing { get; set; } — silent all-null across packages

// Cross-package DTO used in @AuraEnabled return global class InvoiceLineDTO { global String productName; // no { get; set; } global Decimal quantity; // no { get; set; } global Decimal unitPrice; // no { get; set; } } // Works perfectly in unit tests (same package context) // In managed package install: ALL properties deserialize as null // /audit-pull-request: doesn't know ADR-0007 exists // /code-review: reads CLAUDE.md, flags missing { get; set; } accessors
Why it matters: This is one of the most insidious Salesforce managed package bugs. Properties without { get; set; } serialize as null across package boundaries. Unit tests pass because they run in the same namespace. The bug only appears in customer orgs after package install. ADR-0007 exists specifically because this has bitten us before.
RUNTIME — invisible in tests, breaks in prod installs

Why it matters: ServiceLocator.resolve() depends on Custom Metadata wiring. There's no compile-time check. The audit skill only reads the diff — it literally cannot see the CMDT record that still points to the old class name. /code-review opens related files beyond the diff and catches the broken contract.
