🎯 What it covers

AC3 — Per-SKU price history BMS-3889

New getAccountItemPriceHistory(accountId, itemId) returns a SKU's Front_Line_Price__c changes — group-book + this account's exceptions — newest-first with prev→new deltas. A per-row "View history" button lazy-loads an inline timeline. Each change now also carries a change reason (new field, see note).

AC4 — Admin cost & margin BMS-3889

getAccountPricingPanel returns canViewCost (FLS check on Item.Last_Landed_Case_Cost__c) and, when allowed, per-row unit cost, margin $/case, and GM % — measured against the net price the account pays. Reps/drivers without cost FLS never see them; the panel shows a compact cost/margin line (red when margin is negative).

Applied promotions overlay + preview-scoped QD tiers BMS-5708

Promotions actually applied to the account surface on the panel (expandable "active promos" chip in the hero band, with promo savings). Quantity-discount tiers are preview-scoped so catalog previews don't cross-contaminate real cart resolution. (AC2 read-only, AC5 per-warehouse isolation, AC6 pagination+filters already shipped separately.)
