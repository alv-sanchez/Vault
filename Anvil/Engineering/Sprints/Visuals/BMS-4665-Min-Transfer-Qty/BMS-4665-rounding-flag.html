Enforce_Layer_Pallet_Rounding__c

A checkbox on Transfer_Threshold__c that adds a second, independent check on top of the minimum: the quantity moved must be a whole multiple of the unit — no partial layers / pallets (or partial cases).

01 Two independent checks

A quantity can pass the minimum but fail rounding. They are evaluated separately inside enforceMinTransferQuantity.

① Minimum ALWAYS (if matched)

When it runs

every matched threshold

What it asserts

totalCases ≥ Min_Quantity × casesPerUnit
② Rounding multiple CONDITIONAL

When it runs

group Use_Pallets_And_Layers__c = true AND threshold Enforce_Layer_Pallet_Rounding__c = true

What it asserts

totalCases is a whole multiple of casesPerUnit

03 The multiple follows Quantity_Unit__c

Cases
multiple of 1 → effectively "whole cases, no partial case"
Layers
multiple of Item.Cases_Per_Layer__c → "whole layers"
Pallets
multiple of Item.Cases_Per_Pallet__c → "whole pallets"

05 When the rounding check fires

All three must hold — otherwise only the minimum is enforced.

IFTransfer_Group__c.Use_Pallets_And_Layers__c = truegroup is in pallet/layer mode — if not, the flag is ignored entirely
ANDTransfer_Threshold__c.Enforce_Layer_Pallet_Rounding__c = true
ANDitem has Cases_Per_Layer__c / Cases_Per_Pallet__cmissing factor → skipped, not blocked
→ then: totalCases must be a whole multiple of casesPerUnit, else block.

06 Use cases

When to reach for the flag (and when to leave it off). Each is a Transfer_Threshold__c config on an item + lane.

FLAG ON · Pallets
Full-pallet-only lane

Gulf moves a fast SKU between two DCs and wants only whole pallets on the truck for clean loading/unloading. Unit=Pallets · Min=1 · Rounding ✓

50 cases (½ pallet) → blocked · 100 / 200 → pass.

FLAG ON · Layers
Layer-pick efficiency

The DC picks by layer; partial layers force manual re-stacking and slow the dock. Force whole layers. Unit=Layers · Min=1 · Rounding ✓

15 cases → blocked (not a whole layer) · 10 / 20 → pass.

FLAG ON · Cases
No-partial-case data guard

Even in pallet/layer mode, block fractional cases from bad entry/conversions (the original v1 behavior). Unit=Cases · Rounding ✓

12.5 cases → blocked · 12 / 13 → pass.

FLAG OFF
Floor only — flexible quantity

A slow / closeout item: just stop trivially small transfers, but partial layers are acceptable (overflow, last-of-stock). Unit=Layers or Cases · Min set · Rounding ✗

15 cases → allowed (≥ min) · only sub-min is blocked.

FLAG OFF · by design
Case-entry transfers

If the group isn't in pallet/layer mode (Use_Pallets_And_Layers__c = false), the flag does nothing — so for case-keyed transfers leave it off; rely on the minimum.

Rounding check never fires regardless of the checkbox.

MIXED PORTFOLIO
Per-item / per-lane tuning

High-velocity SKU on a hub lane → ON, Pallets; tail SKU on the same lane → OFF, floor only. Thresholds are per item+lane, so policies coexist.

One object, many rules — most-specific lane wins, ties → strictest.

Watch-out: turning on Layers/Pallets rounding for an item that has no Cases_Per_Layer__c / Cases_Per_Pallet__c → the rule is silently skipped (not blocked). Set the item's conversion factors first, or use Unit = Cases.
In one line
It enables the "no partial layers/pallets" rule for pallet/layer-mode transfers — separate from, and in addition to, the minimum. Unchecked = the rule enforces a floor only, not the increment.
